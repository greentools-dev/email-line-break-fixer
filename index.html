Unwrapper Guide & Frequently Asked Questions

How does the unwrapping algorithm work?

The parser analyzes newline boundaries. If a line break occurs between two regular words without terminating punctuation (like a period, colon, or question mark), the return is collapsed into a single space. When a double newline or list marker is detected, the structure is preserved.

How does it handle email quotation markers?

Forwarded emails often accumulate multiple nested quote markers (e.g., > > text). When the "Strip Email Quotes" option is enabled, these characters are removed before sentences are reconstructed.

Does it affect code snippets?

For source code or indented blocks, lines starting with significant whitespace or specific punctuation are treated as discrete lines rather than merged into a single sentence.

Is this tool private?

100% private. All regex transformations execute locally in browser memory. Sensitive emails, contracts, and confidential documents never leave your local device.
